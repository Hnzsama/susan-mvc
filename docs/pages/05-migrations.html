Migrasi Database & Seeder 🗄️

Ubah struktur tabel layaknya Version Control (Git) tanpa perlu repot buka phpMyAdmin manual.

Apa itu Migrasi?

Migrasi adalah cetak biru (blueprint) tabel database kamu dalam kode PHP. Jika teman setim kamu clone project, mereka cukup jalankan php susan migrate dan database langsung siap 100%!

1. Membuat File Migrasi Baru
Bash Terminal 
php susan make:migration add_gambar_to_produk_table
2. Menulis Isi File Migrasi (Method up() dan down())
PHP database/migrations/m0007_add_gambar_to_produk_table.php 
<?php
class m0007_add_gambar_to_produk_table {
    public function up(Database $db) {
        $db->query("ALTER TABLE produk ADD COLUMN gambar TEXT NULL");
        $db->execute();
    }

    public function down(Database $db) {
        // Rollback query
    }
}
3. Mengisi Data Dummy dengan Seeder
Bash Terminal 
php susan db:seed
