Bagaimana Composer Bekerja di Susan MVC?

Autoload Otomatis via vendor/autoload.php

Susan MVC secara otomatis mendeteksi dan memuat vendor/autoload.php di file app/init.php jika folder vendor/ tersedia.

1. Install Package dari Terminal
composer require nesbot/carbon
2. Gunakan di Controller / Rute / View
PHP Contoh Penggunaan Carbon 
use Carbon\Carbon;

Route::get('/demo-composer', function() {
    Carbon::setLocale('id'); // Bahasa Indonesia

    $sekarang = Carbon::now();
    $waktuLalu = Carbon::now()->subMinutes(25);

    echo "Sekarang: " . $sekarang->translatedFormat('l, d F Y');
    echo "Relatif: " . $waktuLalu->diffForHumans(); // "25 menit yang lalu"
});
