Selamat Datang di Susan PHP MVC! 🍼

Framework PHP Modern, Ringan, dan Terstruktur dengan Kenyamanan (Developer Experience) ala Laravel.

👶

Analogikan Susan seperti Restoran Bintang 5!

Kenapa kita butuh MVC? Mari kita pahami dengan analogi bayi:

Bayangkan kamu sedang makan di sebuah restoran mewah:

1. Controller (Pelayan)

Menerima pesanan dari pengunjung (Browser/User), lalu menyuruh Koki memasak dan mengantarkan makanan yang sudah jadi ke meja kamu.

2. Model (Koki di Dapur)

Bertugas mengambil bahan mentah dari gudang/kulkas (Database) dan memasaknya sesuai instruksi.

3. View (Penyajian Piring)

Tampilan piring yang cantik, garnish indah, dan layout yang kamu lihat dan nikmati di meja makan (HTML/CSS).

Kenapa ini keren? Kode kamu tidak lagi campur aduk seperti mie instan gosong! Logika database terpisah rapi dari tampilan visual dan routing.

Fitur Unggulan Susan Framework

Laravel-style Routing & Middleware:

Daftarkan URL via Route::get(), proteksi rute dengan ->middleware('auth').

Active Record ORM & Relasi:

Query database tanpa SQL manual: all(), find(), create(), relasi 1:1, 1:N, N:M.

Filesystem Storage & Upload:

Simpan berkas dan gambar via Storage::putFile() dan php susan storage:link.

Dukungan Package Composer:

Gunakan ribuan library PHP favoritmu langsung melalui vendor/autoload.php.
