Validasi Request & Flash Messages 🛡️

Cegah data sampah masuk ke database dengan aturan validasi ala Laravel Request Validator.

Aturan Validasi yang Didukung (Validation Rules)

Rule Contoh Aturan Arti / Makna
required 'nama' => 'required' Wajib diisi, tidak boleh kosong.
min:X 'nama' => 'min:3' Panjang string minimal X karakter atau angka minimal bernilai X.
max:X 'nama' => 'max:100' Panjang maksimal X karakter.
numeric 'harga' => 'numeric' Harus berupa angka (desimal/bulat).
integer 'stok' => 'integer' Harus berupa bilangan bulat.
email 'email' => 'email' Harus berupa format email yang valid.
Contoh Penggunaan di Controller
PHP Validasi di Controller 
public function store() {
    // Validasi input: Jika gagal, otomatis flash error dan redirect kembali!
    $validated = $this->validate([
        'nama'     => 'required|min:3|max:150',
        'kategori' => 'required|string',
        'harga'    => 'required|numeric|min:1000',
        'stok'     => 'required|integer|min:0'
    ], $_POST, 'product/create');

    Product::create($validated);
    Session::flash('success', 'Produk berhasil ditambahkan!');
    return redirect('product');
}
