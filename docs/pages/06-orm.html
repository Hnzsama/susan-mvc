Bab 6: Manipulasi Data

Active Record ORM & Relasi Antar Tabel 🪄

Ambil, simpan, ubah, dan hubungkan tabel relasi (1:1, 1:N, N:M) tanpa menulis query JOIN yang rumit.

1. Operasi Dasar CRUD pada Model

Operasi Contoh Kode Susan ORM Penjelasan
Ambil Semua Data $produk = Product::all(); Mengambil seluruh baris dalam tabel produk.
Cari Berdasarkan ID $item = Product::find($id); Mengambil 1 baris berdasarkan Primary Key id.
Filter (WHERE) $murah = Product::where('harga', '<', 50000); Filter baris dengan kondisi tertentu.
Tambah Data Baru $newId = Product::create([...]); Menyimpan baris baru dan mengembalikan ID auto-increment.
Update Data Product::update($id, [...]); Mengubah data baris dengan ID tertentu.
Hapus Data Product::delete($id); Menghapus data baris dengan ID tertentu.

2. Tiga Jenis Relasi Antar Tabel (ORM Relations)

One-to-One (1:1)

Satu produk punya satu spesifikasi detail.

$detail = Product::detail($id);
One-to-Many (1:N)

Satu produk punya banyak ulasan dari user.

$reviews = Product::reviews($id);
Many-to-Many (N:M)

Produk punya banyak tag via tabel pivot.

$tags = Product::tags($id);
