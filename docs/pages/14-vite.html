Integrasi Vite & Hot Reload ⚡

Edit CSS atau JS tanpa perlu refresh halaman browser manual secara berulang kali.

Bagaimana Vite Bekerja di Susan MVC?

Fungsi pembantu vite('resources/css/app.css') secara otomatis menghubungkan script HMR dev saat server Vite aktif, atau membaca bundle public/build/ saat mode production.

PHP Helper vite() di Header 
<head>
    <title><?= $judul ?? APP_NAME ?></title>
    <?= vite('resources/css/app.css') ?>
</head>
