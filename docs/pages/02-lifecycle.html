Bab 2: Di Balik Layar

Bagaimana Sebuah Halaman Muncul? 🔄

Langkah demi langkah apa yang terjadi dari saat kamu menekan Enter di browser sampai halaman muncul.

Peta Perjalanan Request (Request Lifecycle)

1
User Mengetik URL di Browser

Contoh: http://127.0.0.1:8000/product. Request dikirim ke server dan diterima pertama kali oleh file public/index.php (Pintu Gerbang Utama).

2
Bootstrap & Inisialisasi (app/init.php)

Susan membaca .env, memulai sesi PHP (Session::start()), memuat autoloader Composer (vendor/autoload.php), koneksi PDO database, dan daftar rute di routes/web.php.

3
Pencocokan Rute & Pemeriksaan Middleware

Router memeriksa kecocokan URL. Jika ada middleware (satpam) terpasang, request dicek dulu (contoh: apakah sudah login?). Jika lolos, barulah diteruskan ke controller.

4
Controller Bertindak & Berbicara ke Model

ProductController meminta data produk ke Product::all(). Model mengambil baris data dari tabel database SQLite/MySQL.

5
Rendering View & Dikirim Kembali ke Browser

Controller merender resources/views/product/index.php dengan data produk, lalu mengirimkan HTML final ke layar pengguna. Selesai!
