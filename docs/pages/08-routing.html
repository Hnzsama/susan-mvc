Routing Expressive (routes/web.php) 🛣️

Deklarasi URL bersih, parameter dinamis {id}, dan pembagian HTTP Method yang rapi.

Cara Mendaftarkan Rute di routes/web.php

PHP routes/web.php 
<?php
// Rute GET Biasa
Route::get('/', [HomeController::class, 'index']);
Route::get('/home', [HomeController::class, 'index']);

// CRUD Produk
Route::get('/product', [ProductController::class, 'index']);
Route::get('/product/create', [ProductController::class, 'create']);
Route::post('/product/store', [ProductController::class, 'store']);

// Parameter Dinamis {id}
Route::get('/product/edit/{id}', [ProductController::class, 'edit']);
Route::post('/product/update', [ProductController::class, 'update']);
Route::get('/product/delete/{id}', [ProductController::class, 'delete']);

// Route dengan Closure (Fungsi Anonim)
Route::get('/ping', function() {
    echo "Pong! Susan MVC siap melayani.";
});
