Bab 11: Satpam Rute

Middleware Pipeline (Satpam Request) 👮‍♂️

Filter setiap pengunjung sebelum mereka berhasil masuk ke dalam Controller!

👮

Analogikan Middleware seperti Satpam Klub Malam!

Siapa yang boleh masuk dan siapa yang harus ditolak?

Bayangkan kamu ingin masuk ke area VIP di sebuah pesta:

1. Belum Login (Tanpa Tiket)

Satpam AuthMiddleware menghadangmu di pintu dan menyuruhmu login dulu.

2. Bukan Admin

Satpam AdminMiddleware memeriksa gelangmu. Jika bukan admin, akses ditolak!

3. Syarat Terpenuhi ($next())

Satpam membuka pembatas dan mempersilakanmu masuk (Controller dieksekusi!).

1. Memasang Middleware pada Rute
PHP routes/web.php 
// A. Single Middleware:
Route::get('/vip-area', [VipController::class, 'index'])->middleware('auth');

// B. Multi Middleware Berantai:
Route::post('/product/store', [ProductController::class, 'store'])->middleware(['auth', 'admin']);

// C. Route Grouping:
Route::middleware(['auth'])->group(function() {
    Route::get('/dashboard', [DashboardController::class, 'index']);
    Route::get('/profile', [UserController::class, 'profile']);
});
2. Membuat Middleware Baru via CLI
php susan make:middleware CheckRole
