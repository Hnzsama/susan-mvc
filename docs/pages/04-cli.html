Bab 4: Tongkat Sihir Terminal

Kamus Lengkap CLI php susan ⚡

Semua perintah ajaib terminal yang tersedia untuk mempermudah hidupmu saat ngoding.

Daftar Lengkap Command

Ketik perintah ini di terminal root proyekmu:

php susan dev
Jalankan Server Dev + Vite (Live Reload)

Menjalankan server web PHP (port 8000) sekaligus server frontend Vite. Setiap kamu edit CSS/JS, browser otomatis update!

php susan serve [8080]
Jalankan PHP Web Server Saja

Hanya menjalankan PHP built-in server tanpa Vite. Port opsional (default: 8000).

php susan build
Kompilasi Asset Production

Mengompresi dan membundel CSS/JS ke folder public/build/ siap upload ke hosting.

php susan storage:link
Hubungkan Storage Publik (Symlink)

Membuat jembatan penghubung public/storage -> storage/app/public agar file yang diupload bisa dibuka browser.

php susan migrate
Jalankan Migrasi Database

Mengeksekusi semua file migrasi baru di database/migrations/ dan mencatat batch ke database.

php susan migrate:rollback
Batalkan Migrasi Terakhir

Mengembalikan (rollback) perubahan batch migrasi terakhir yang baru dijalankan.

php susan make:middleware CheckRole
Buat Middleware Satpam Baru

Membuat file class middleware baru di app/middlewares/CheckRoleMiddleware.php.

php susan make:controller Order
Buat Controller CRUD Otomatis

Menghasilkan file app/controllers/OrderController.php lengkap dengan method index, create, store, edit, update, delete.

php susan make:model Order -m
Buat Model (+ Migrasi dengan -m)

Membuat file model di app/models/Order.php dan otomatis membuat file migrasi jika memakai flag -m.

php susan route:list
Tampilkan Tabel Semua Route & Middleware

Melihat daftar semua URI, Method (GET, POST, PUT, DELETE), Action, dan Middleware yang terpasang.
