Cheatsheet Helper Global 🪄

Daftar fungsi pembantu global di Susan PHP MVC Framework.

Helper Contoh Kode Deskripsi
url($path) url('product/create') Menghasilkan URL lengkap aplikasi
redirect($url, $flash) redirect('product', ['success' => 'OK']) Pindah halaman dengan flash message
csrf_field() <?= csrf_field() ?> Input hidden token CSRF form
csrf_token() $token = csrf_token(); String token CSRF aktif sesi
Storage::url($path) Storage::url($p['gambar']) URL publik file di upload storage
env($key, $default) env('APP_NAME', 'Susan') Ambil konfigurasi dari file .env
dd(...$vars) dd($produk, $_POST); Dump and Die untuk debugging
