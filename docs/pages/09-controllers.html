Controller & Request Handling 🧠

Pusat komando yang mengatur alur logika bisnis, menerima input, dan memanggil view.

Struktur Standar Controller

Setiap controller mewarisi class Controller utama, sehingga langsung memiliki akses ke helper $this->view() dan $this->validate().

PHP app/controllers/ProductController.php 
<?php
class ProductController extends Controller {
    public function index() {
        $data['judul'] = 'Daftar Produk';
        $data['produk'] = Product::all();

        $this->view('templates/header', $data);
        $this->view('product/index', $data);
        $this->view('templates/footer');
    }

    public function create() {
        $data['judul'] = 'Tambah Produk';
        $this->view('templates/header', $data);
        $this->view('product/create', $data);
        $this->view('templates/footer');
    }
}
