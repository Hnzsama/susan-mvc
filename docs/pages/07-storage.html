Bagaimana Cara Kerja Storage di Susan MVC?

Aman, Terstruktur, dan Terlindungi dari Akses Liar!

Semua berkas yang diunggah disimpan di folder terlindung storage/app/public/. Agar browser dapat membukanya, buatlah Symbolic Link ke public/storage:

php susan storage:link
Kamus Method Storage Helper:
Method Contoh Pemanggilan Kegunaan
Storage::putFile() Storage::putFile('products', $_FILES['gambar']) Upload file dari form $_FILES, buat nama unik otomatis, dan simpan di folder tujuan.
Storage::url() Storage::url($path) Menghasilkan URL publik untuk tag <img src="...">.
Storage::delete() Storage::delete($path) Menghapus file dari disk fisik storage secara permanen dan aman.
Storage::exists() Storage::exists('products/foto.jpg') Mengecek apakah file benar-benar ada di storage.
