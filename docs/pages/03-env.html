Setup Lingkungan & File .env ⚙️

Tempat rahasia menyimpan password, database, dan konfigurasi tanpa takut bocor ke GitHub.

Apa itu File .env?

File .env adalah buku catatan rahasia aplikasi kamu. Di sinilah kamu menentukan apakah aplikasi berjalan di laptop sendiri (lokal) atau server online (production), serta menghubungkan database SQLite atau MySQL.

.env (Konfigurasi Aplikasi) 
# Nama & Lingkungan Aplikasi
APP_NAME="Inainu MVC Studio"
APP_ENV=development
APP_URL=http://127.0.0.1:8000/

# Pengaturan Database Default (SQLite - Langsung jalan tanpa install server DB!)
DB_DRIVER=sqlite
DB_FILE=../database.sqlite

# Atau jika ingin memakai MySQL (Aktifkan baris ini):
# DB_DRIVER=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_NAME=inainu_db
# DB_USER=root
# DB_PASS=

# Pengaturan Filesystem Storage
FILESYSTEM_DISK=public
Cara Mengambil Nilai .env di Kode PHP:
Gunakan fungsi global env('NAMA_KEY', 'nilai_default_jika_kosong').
PHP Contoh Penggunaan env() 
// Mengambil nama aplikasi dari .env
$appName = env('APP_NAME', 'Susan MVC');

// Mengambil konfigurasi disk storage
$disk = env('FILESYSTEM_DISK', 'public');
