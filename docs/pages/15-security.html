Bab 15: Benteng Pertahanan

Keamanan Super Kuat 🛡️

Susan dirancang dengan perlindungan lapis tiga terhadap serangan web.

1. CSRF Protection
Cegah Pemalsuan Request

Setiap form POST wajib menyertakan token rahasia <?= csrf_field() ?>.

2. SQL Injection Immunity
100% Prepared Statements

Semua query Model dan Database menggunakan PDO parameter binding (:id, :nama).

3. XSS Escaping
Pencegahan Script Jahat

Output teks di View dibungkus dengan htmlspecialchars().
